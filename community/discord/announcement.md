# Copy-ready Discord announcement

> **TIDE — a terminal IDE for code, shells, and AI agents**
>
> TIDE turns one command into a complete tmux development workspace: a native
> Rust editor and project Explorer, one or more coding-agent panes, and a project
> shell.
>
> **Highlights**
> • Explorer with Git status and live refresh
> • Tabs, syntax highlighting, undo/redo, and safe saving
> • Quick Open and project-wide content search
> • Multiple agents with `::`
> • External-edit synchronization for agent workflows
> • Image, PDF, video-thumbnail, font, and binary previews
> • Linux, macOS, Windows editor, and full WSL support
> • Native Omarchy app integration and optional bar launcher
>
> **Install on Omarchy**
> ```bash
> curl -fsSL https://raw.githubusercontent.com/nasazzam/tide/main/packaging/omarchy/install.sh | bash
> ```
>
> **Optional Omarchy bar button**
> ```bash
> omarchy plugin add https://github.com/nasazzam/tide.git --enable
> ```
>
> Then launch any agent:
> ```bash
> tide pi -c
> tide claude --continue
> tide pi -c :: claude --continue
> ```
>
